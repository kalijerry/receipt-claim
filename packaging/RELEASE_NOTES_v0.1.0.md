报销助手 Windows 版第一个发布版：不需要安装 Python，不需要联网，解压后双击就能用。

## 下载和使用
1. 下载 `receipt-claim-windows-x64-v0.1.0.zip`（约 168 MB），解压整个文件夹（路径里有中文或空格都可以）。
2. 双击 `报销助手.exe`，会出现一个黑色窗口和浏览器页面。**黑色窗口请保持打开**，关闭它就是退出。
3. 新建出差 → 填报销日期 → 导入票据照片（JPG / PNG / HEIC）→ 逐单核对 → 生成报销包（改好名的票据、带公式的 Excel、A4 扫描版 PDF）。

票据和生成的文件都保存在 exe 旁边的 `output` 文件夹，只在本机，不会上传。升级时把 `output` 文件夹复制到新版本里即可。更详细的说明在压缩包里的 `使用说明.txt`。

Windows 10 / 11，64 位。

## 这一版有什么
- **两个独立的识别模型**（PP-OCRv5 英文 + PP-OCRv4 中文）各读一遍，一致才算有把握，不一致就在核对窗口里提示，并把另一个读到的金额 / 日期放在一键可选的位置。
- **日期会和别的证据交叉校验**：照片的拍摄时间、这次出差的日期段、「不会是三年前」；也能容忍 `050CT2026`、`0ct`、日期和时间粘在一起、`f11.50` 这类 OCR 笔误。
- **自动选最快的运行方式**：第一次启动时在这台电脑上实测 CPU、DirectML（NVIDIA / Intel / AMD 显卡）、OpenVINO（CPU 或 Intel 核显），要求识别结果与 CPU 一致，选最快的，结果记在 `%LOCALAPPDATA%\receipt-claim\`。通常比单纯 CPU 快一倍；扫描版一张约 1.5 秒。
- 识别模型已内置，全程离线。

## 准确度（一次 28 张真实票据的出差，每张都经人工核对）
| | 金额命中 | 印刷日期读出 | 需人工关注 | 识别错了却没提示 |
|---|---|---|---|---|
| 本版 | 96.4% | 100% | 32.1% | 0 张 |

在旋转、梯形、模糊、压缩、欠曝、缩小共 196 张退化照片上，「识别错了却没提示」为 2 张（均是两个模型读出了同样的错）。样本只有一次出差，数字仅供参考；金额和日期最终仍需你逐单确认。

## 注意
- **没有代码签名**：第一次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，点「更多信息」→「仍要运行」。杀毒软件如果误报，请把文件夹加入信任列表。
- OpenVINO 的 Intel 核显路径没有在真实的 Intel 核显机器上验证过。它和其他方式一起被自动实测，不可用或结果不一致会自动放弃，最坏情况回到 CPU。
- macOS 版请从源码运行（`启动报销助手.command`），见 README。
