## 新功能：从 EHR 出差截图识别报销日期
不用再一段一段手填报销日期了。

1. 在第 1 步「报销日期」里点「从 EHR 出差截图识别」。
2. 选择、拖入或直接 Ctrl+V 粘贴 EHR「我的出差」列表的截图。截图要包含「开始时间」「结束时间」两列。
3. 识别出的出差会连同时长、事由和审批状态一起列出。勾选这次要报销的几条，点「添加到报销日期」即可。

- **不足一天按一天算**：天数按日期算，首尾两天都算，所以 EHR 里的 1.5天（例如 12:00 出发、第二天 18:00 回）算 2 天。
- 默认只勾选「通过」且还没加过的出差；驳回、审批中的会置灰。EHR 时长取整与日期天数不一致时会标黄提示核对。
- 日期段旁会显示出差事由。
- 截图只在本机识别，识别完即删除，不会上传。

## 下载
- **macOS**：`receipt-claim-macos-v0.2.0.dmg`（由 GitHub Actions 自动构建，未签名）。打开后双击 `启动报销助手.command`，第一次运行会自动安装依赖。
- **Windows**：从源码运行 `启动报销助手.bat`；也可以继续用 v0.1.0 的 exe（不含本功能）。

升级时把旧版本的 `output` 文件夹复制过来即可，已有出差数据完全兼容。
