报销助手（macOS 版）

使用
  方式一（推荐）：把 报销助手 文件夹拖到任意位置（桌面、文稿都可以），双击里面的 启动报销助手.command。
  方式二：直接在 DMG 里双击 报销助手 文件夹里的 启动报销助手.command。DMG 是只读的，
         程序会先把自己复制到 ~/报销助手，再从那里运行；以后也请从 ~/报销助手 启动。

  第一次启动需要联网，会自动安装 uv（Python 包管理器）、创建虚拟环境、安装依赖，
  再编译文字识别工具，共约一两分钟；之后完全离线，几秒即可启动。
  会打开一个终端窗口和浏览器页面（http://127.0.0.1:8765）。终端窗口请保持打开，关闭它就是退出程序。
  在页面里：新建出差 → 填报销日期 → 导入票据照片 → 逐单核对 → 生成报销包。

数据
  票据、报销表、扫描版 PDF 都保存在 报销助手 文件夹里面的 output 文件夹里，只在这台电脑上，不会上传到任何地方。
  升级：方式二会自动保留 ~/报销助手/output，直接在新版 DMG 里双击即可。
  方式一请先把旧文件夹里的 output 复制出来，换成新版文件夹后再放回去（直接替换文件夹会删掉 output）。

系统要求
  macOS 12 及以上，需要 Xcode Command Line Tools（用来编译文字识别工具）。
  没装的话第一次启动会自动弹出安装窗口，装好之后重新双击即可；也可以先在终端执行 xcode-select --install。

「无法打开，因为无法验证开发者」/「来自身份不明的开发者」
  本程序没有经过 Apple 签名和公证（没有购买开发者账号），macOS 的 Gatekeeper 第一次运行时会拦截。任选一种：
  1. 在 Finder 里按住 Control 点按（或右键）启动报销助手.command，选择「打开」，再在弹窗里确认「打开」。
  2. 如果没有「打开」选项（较新的 macOS）：先双击一次，然后到「系统设置 > 隐私与安全性」，
     拉到最下面点「仍要打开」。
  3. 打开「终端」，输入 bash 加一个空格，把 启动报销助手.command 拖进终端窗口，回车。
     用 bash 运行不经过 Gatekeeper。
  只需做一次。
